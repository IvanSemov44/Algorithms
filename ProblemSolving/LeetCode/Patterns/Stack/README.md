# Stack Pattern

## When to use Stack:
- **Matching pairs** (parentheses, brackets)
- **LIFO (Last In First Out)** operations
- **Backtracking** without recursion
- **Next/Previous element** problems
- **Monotonic stack** for optimization

## Common Use Cases:
1. **Parentheses matching** — validate if brackets are balanced
2. **Decimal to binary conversion** — use stack to reverse digits
3. **Undo/Redo** — maintain history stack
4. **Browser back/forward** — two stacks
5. **Expression evaluation** — postfix/infix conversion

## Problems in this folder:
- **0020 - Valid Parentheses** (Easy) — basic stack matching
- **0155 - Min Stack** (Medium) — stack with constant-time min query
- **0224 - Basic Calculator** (Hard) — evaluate arithmetic expressions

## Key Insight:
When you need to process items in reverse order or compare current item with previous items → **Stack** is your tool.
